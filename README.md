# Исходный код ВКР

Репозиторий содержит исходный код, подготовленный для выпускной квалификационной работы.

## Состав

- `backend/audit-service/` - сервис аудита событий и журналирования действий.
- `backend/monitoring-service/` - сервис мониторинга backend-стека.
- `backend/protocol-service/` - измененные файлы protocol-service, связанные со строгой структурной валидацией сообщений.
- `research/` - исследовательские сценарии и утилиты для раздела 5.
- `tests/pytest/` - интеграционные и статические тесты для проверяемых сценариев.

## Основные части

### Audit Service

Сервис принимает события от backend-сервисов, сохраняет audit-журнал и предоставляет endpoints для получения событий по сессиям и проверки полноты журнальных записей.

### Monitoring Service

Сервис выполняет проверки доступности backend-сервисов, сохраняет результаты проверок и предоставляет endpoints для health, ручного запуска проверки, получения последнего результата и истории.

### Protocol Service

Сервис управляет жизненным циклом протокольных сессий, хранит сообщения и состояния разбирательства, а также обеспечивает структурную привязку сообщений к требованиям и версиям технического задания.

### Research

Пакет содержит сценарии генерации сессий, расчет метрики структурной связанности, восстановление арбитражных ответов по audit-журналу, проверки целостности, нагрузочные сценарии и измерение наблюдаемости.

### Tests

Тесты покрывают FSM-переходы, RBAC, monitoring endpoints, blind recovery и расширенные проверки protocol-service.
